School Management System Documentation
======================================

This project provides Tkinter and PyQt5 interfaces for the same school
management model and SQLite database. Run one interface at a time from the
repository directory so each starts with the latest saved records.

**Student:** Hassan Nasrallah  
**Course:** EECE435L Software Tools Laboratory  
**Version:** 1.0

The Tkinter API reference uses the Sphinx-style docstrings added in Lab 3.
The PyQt5 reference shows the module and its available members.
